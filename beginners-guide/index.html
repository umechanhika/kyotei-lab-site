競艇初心者ガイド|舟券の買い方とデータの見方

「競艇はまったく初めて」という方向けに、レースの基本と舟券の買い方、データの見方を最短ルートでまとめました。

競艇はどんなレース?

競艇(ボートレース)は6艇で争う公営競技です。1周600mの水面を3周し、着順を予想して舟券を購入します。出走数が6艇と少なく、内側のコースが構造的に有利なため、公営競技の中では「データが結果に反映されやすい」競技と言われます。特に1コースの1着率は全国平均で5割を超えます。

舟券の種類

初心者がまず覚えるべきは次の3つです。

券種当て方組み合わせ数
単勝1着の艇を当てる6通り
2連単1・2着を着順どおり当てる30通り
3連単1〜3着を着順どおり当てる120通り

当サイトの予想は3連単6点のフォーメーション(軸1頭+相手3艇)です。用語の意味は用語集を参照してください。

舟券を買うまでの3ステップ

競艇場へ行かなくても、公式のインターネット投票(テレボート)で全国24場の舟券を買えます。

  1. 投票会員に登録する — 公式サイトから申し込み、指定の銀行口座を登録します。登録できるのは20歳以上の方だけです。
  2. 購入資金を入金する — 登録した口座から、その日に使う分だけを入金します。先に上限を決めて入れておくと、熱くなったときの歯止めになります。
  3. レースと買い目を選んで購入する — 場・レース番号・券種・買い目・金額を指定して確定します。締切時刻を1分でも過ぎると買えないので、締切の数分前までに済ませてください。

買い目の組み方(フォーメーション・流し・ボックス)

3連単は120通りあるので、全部は買えません。そこで「どう絞るか」の型が3つあります。ここでは1号艇を軸にした例で見ます。

組み方書き方の例点数向いている場面
フォーメーション1 → 2,3,4 → 2,3,46点1着は決め打ちできるが、2・3着の順番が読めないとき
流し(1着固定)1 → 全 → 全20点1着の信頼度は高いが、2・3着がまったく読めないとき
ボックス1,2,3 ボックス6点上位3艇は絞れるが、着順がまったく読めないとき

フォーメーションの「1 → 2,3,4 → 2,3,4」は、1着を1号艇に固定し、2着と3着に2・3・4号艇を入れる、という意味です。2着と3着に同じ艇は入らないので、3×3から重複する3通りを除いて6点になります。当サイトの予想が毎回6点なのはこの形だからです。

点数を増やせば当たる確率は上がりますが、1点あたりの取り分は減ります。「当たったのに負ける」のはこの型を広げすぎたときに起きます。

出走表のどこを見るか

最初は次の4つだけで十分です。いずれも当サイトのAIが使っている特徴量です。

  • 枠番 — 内側ほど有利。1号艇の信頼度がレース選びの軸になる
  • 級別 — A1選手は実力上位。B2との混走なら力差が出やすい
  • 全国勝率・当地勝率 — 選手の地力と水面への相性
  • モーター2連率 — 機力の目安。40%を超えれば上位機

資金管理が最重要

どんな予想でも外れる日は必ずあります。舟券は余裕資金の範囲で、1日の上限額を決めてから購入してください。20歳未満の方は舟券を購入できません。当サイトも全予想の的中・不的中を毎日そのまま公開しています。良い日だけを切り取らない数字を、購入判断の材料にしてください。

はじめのうちに気をつけること

  • 全レースを買わない — 1日に開催されるレースは全国で百数十あります。条件の良いものだけを選ぶほうが、収支は安定しやすくなります。
  • 点数を広げすぎない — 当たっても払戻が購入額を下回ることがあります。買い目を足すときは、増えた点数の分だけ配当が見合うかを確認してください。
  • 負けを取り返そうとしない — 外した直後に金額を上げるのが、1日の損失が膨らむいちばん多いパターンです。上限額は先に決めておきます。
  • 当たった日だけの数字を信じない — 的中報告は誰でも良い日だけを見せられます。全期間の的中率と回収率が公開されているかどうかで判断してください。
